# Risk-Controlled Multi-Device NIR Spectroscopy for Textile Fiber Composition Identification and Recycling-Oriented Sorting

Textile recycling needs fast and reliable identification of fabric composition, especially when products contain mixed fibers or lack accurate labels. This study presents a near-infrared spectroscopy method for identifying textile fiber composition across one benchtop and two handheld instruments. The dataset includes 113 fabric specimens from the Bangladeshi textile industry, covering pure cotton, polyester, nylon, wool, viscose, and cotton-polyester blends from raw materials, production offcuts, finished products, and post-consumer items. Spectra were processed using standard normalization and a first-derivative filter. They were then reduced with principal component analysis. A calibrated Ridge model was used for classification. The system also used a confidence-based review step, which sent uncertain samples to manual inspection instead of accepting risky predictions. The main classifier achieved 98.6% label accuracy and 99.6% balanced accuracy on the test set. With the review policy, it reached 98.6% purity at 97.8% automatic coverage. Only 2.2% of samples needed manual review. A composition-aware layer improved label accuracy to 99.7% and provided useful sorting outputs, including dominant fiber, blend status, fiber fractions, recoverability, and sorting difficulty. The results show that the method supports practical textile sorting across different instruments. It also reduces harmful errors in recycling streams.
